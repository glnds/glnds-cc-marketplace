# ty-lsp

Python language server (ty) for type checking and code intelligence.

## Installation

```text
claude plugin marketplace add glnds/glnds-cc-marketplace
claude plugin install ty-lsp@glnds-cc-marketplace
```

## Prerequisites

- `uv` on `PATH` (the server runs as `uvx ty server`)

Gives Claude ty diagnostics and symbol navigation for `.py` and `.pyi` files.
