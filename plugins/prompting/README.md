# prompting

Prompting techniques such as verbalized sampling.

## Installation

```text
claude plugin marketplace add glnds/glnds-cc-marketplace
claude plugin install prompting@glnds-cc-marketplace
```

## Skills

### `prompting:verbalized-sampling`

Generate several answers with probabilities to escape mode collapse and see the
response distribution. Useful for brainstorming and creative tasks.
