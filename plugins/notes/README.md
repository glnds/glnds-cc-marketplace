# notes

Obsidian-backed skills: make notes, spar on ideas, enhance text.

## Installation

```text
claude plugin marketplace add glnds/glnds-cc-marketplace
claude plugin install notes@glnds-cc-marketplace
```

## Skills

### `notes:make-note`

Create Obsidian notes from the vault's Note Template, with tag suggestions from live
vault tags.

### `notes:sparring`

Critical-thinking partner for technical ideas and strategy, grounded in your Obsidian
notes and, for AWS topics, AWS documentation.

### `notes:text-enhancer`

Grammar, clarity and fact-check pass on professional and technical text. Triggers on
"enhance" or "polish".

## Prerequisites

- An Obsidian MCP server (`obsidian_*` tools)
- Optional: AWS Documentation MCP server (`sparring`, `text-enhancer`)
